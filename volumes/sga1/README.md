# SGA 1 : le texte français est sur arXiv

Alexander Grothendieck, avec Michèle Raynaud, *Revêtements étales et groupe fondamental* (SGA 1), Séminaire de géométrie algébrique du Bois-Marie 1960–1961, Lecture Notes in Mathematics 224, Springer, 1971.

Le texte français de référence est la nouvelle édition mise à jour, retapée en LaTeX par le projet dirigé par Bas Edixhoven, avec les remarques de mise à jour de Michel Raynaud : arXiv math/0206203v2 (4 janvier 2004), https://arxiv.org/abs/math/0206203v2.

Pourquoi le texte n’est pas ici : la page arXiv ne donne que la licence de distribution non exclusive accordée à arXiv (« a perpetual, non-exclusive license to distribute this article », https://arxiv.org/licenses/assumed-1991-2003/). Cette licence ne permet pas à d’autres de redistribuer le texte ; nous renvoyons donc à arXiv.
