Normal/misprint : 496 = 0/1 ; 497 = 3/2 ; 498 = 0/0 ; 499 = 2/2 ; 500 = 3/2.
Convention à traiter globalement : omission du préfixe IV dans les renvois internes lorsque l'imprimé le donne explicitement ; trois exemples : p. 497, 11.2.1, « IV 3.1.2 » ; p. 498, 11.2.2, « IV 3.1.2 » ; p. 500, 11.3.2, premier renvoi à « IV 5.2 ».
